# DataStart

Учебный сайт для знакомства с анализом данных.

## Содержание

- Четыре шага работы с данными.
- Практическая задача о продажах кофейни.
- Инструменты: LibreOffice Calc, SQL и Python.
- Ответы на частые вопросы.

## Запуск

Открыть папку проекта в VS Code и запустить index.html
через расширение Live Server.

## Технологии

HTML и CSS.
